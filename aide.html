Questions Fréquemment Posées

EDU-RDC est une solution logicielle innovante conçue pour moderniser la gestion administrative des institutions scolaires en République Démocratique du Congo. Le projet a été initié, conçu et piloté par l'Ingénieur Mike TSHIBANGU, Président de la Jeunesse Sociale pour le Développement (JSD), en étroite collaboration avec son équipe technique.

Rendez-vous sur la page principale de gestion des établissements (via l'espace sécurisé ou le menu principal). Vous pourrez y renseigner le nom complet de votre école, votre province, votre commune ainsi qu'un **code secret d'accès** personnel qui protégera l'espace administratif de votre établissement.

Accédez à l'écran dédié aux cartes QR. Après vous être authentifié avec le nom et le code secret de votre école, remplissez le formulaire d'identification (nom, postnom, matricule, photo, etc.). Le système génère instantanément la carte au format officiel (8,5 cm x 5,5 cm). Vous pouvez ensuite utiliser les boutons intégrés pour **Télécharger** la carte en image PNG ou l'**Imprimer** directement.

Oui. Toutes les données (effectifs d'élèves, enseignants, listes de cartes) sont synchronisées et stockées de manière sécurisée via une infrastructure Cloud moderne (Firebase Firestore). Chaque école dispose de ses propres accès cloisonnés par un code secret, garantissant l'intégrité et la confidentialité des informations.

Si vous rencontrez le moindre dysfonctionnement ou si vous avez besoin d'une assistance technique personnalisée, vous pouvez nous envoyer un message directement via notre formulaire de la page Contact.
